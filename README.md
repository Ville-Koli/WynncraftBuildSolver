<h1>Wynncraft build solver </h1> 

Uses pandas and streamlit to build a quick (meant for localhost websites only and use in your own regard) localhost based website for solving 
complex wynncraft builds with given statistical constraints.


<h2> Running the application </h2>

Once you have installed streamlit and (maybe) pandas
you can run this command in the Main folder to run the application

* python -m streamlit run Build_search.py
